# 🧠 Memory Matching Game

A simple Memory Matching Game built using **Python** and **Pygame**.

---

## 🎮 Features

- 4 × 4 Memory Grid
- Mouse Click Controls
- Card Flip Animation
- Match Detection
- Move Counter
- Win Screen
- Restart Game

---

## 🛠 Technologies Used

- Python 3
- Pygame

---

## 📂 Project Structure

```
08_Memory_Matching_Game/
│
├── main.py
├── README.md
├── requirements.txt
└── assets/
```

---

## ▶️ Controls

| Action | Key |
|--------|-----|
| Flip Card | Left Mouse Click |
| Restart | R |

## 🚀 Installation

```bash
pip install pygame
```
