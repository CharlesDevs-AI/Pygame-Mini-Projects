# 🏓 Ping Pong Game

A simple two-player Ping Pong game developed using **Python** and **Pygame**. Players control paddles to hit the ball back and forth while trying to score points.

---

## 📌 Features

- 🏓 Two-player gameplay
- 🎮 Smooth paddle controls
- ⚡ Ball collision physics
- 📊 Live score tracking
- 🔄 Ball resets after scoring
- 🖥️ Simple and clean interface

---

## 🛠️ Technologies Used

- Python 3
- Pygame

## 🎮 Controls

| Player | Keys |
|--------|------|
| Player 1 | W / S |
| Player 2 | ↑ / ↓ |

## ▶️ How to Run

### Install Pygame

```bash
pip install pygame
```

### Run the Game

```bash
python main.py
```
