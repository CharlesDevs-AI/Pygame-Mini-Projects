# 🎮 Pygame Mini Projects

A collection of **10 beginner-friendly game development projects** built using **Python** and **Pygame**. This repository is designed to help beginners learn game development concepts such as movement, collision detection, game loops, event handling, scoring systems, and basic game mechanics.

## ▶️ Getting Started

### 1. Clone the Repository

```bash
git clone https://github.com/CharlesDevs-AI/Pygame-Mini-Projects.git
```

### 2. Navigate to the Repository

```bash
cd Pygame-Mini-Projects
```

### 3. Install Pygame

```bash
pip install pygame
```

### 4. Run Any Project

Example:

```bash
cd 01_Ping_Pong_Game
python main.py
```
