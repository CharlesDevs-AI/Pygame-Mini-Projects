# 🏎️ Racing Game

A simple 2D Racing Game built using **Python** and **Pygame**.

## Features

- Player car movement
- Random enemy cars
- Score counter
- Increasing difficulty
- Collision detection
- Restart option

## Controls

- ⬅️ Left Arrow – Move Left
- ➡️ Right Arrow – Move Right
- R – Restart
- ESC – Exit

## Technologies

- Python
- Pygame

## Run

```bash
pip install pygame
python main.py
```
