# ❌⭕ Tic Tac Toe GUI

A simple Tic Tac Toe game built using **Python** and **Pygame**.

---

## Features

- ❌ X vs ⭕ O gameplay
- 🖱️ Mouse click controls
- 🏆 Win detection
- 🤝 Draw detection
- 🔄 Restart game
- 🎨 Clean graphical interface

---

## Technologies Used

- Python
- Pygame

## Controls

| Key | Action |
|------|--------|
| Mouse Click | Place X / O |
| R | Restart Game |
| Close Window | Exit |
