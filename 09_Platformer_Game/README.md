# 🕹️ Platformer Game

A simple 2D Platformer Game built using **Python** and **Pygame**.

---

## 🎮 Features

- Player Movement
- Jump Mechanics
- Platforms
- Gravity Physics
- Collision Detection
- Win Condition
- Restart Option

---

## 🛠 Technologies Used

- Python 3
- Pygame

---

## 📂 Project Structure

```
09_Platformer_Game/
│
├── main.py
├── README.md
├── requirements.txt
└── assets/
```

---

## 🎮 Controls

| Key | Action |
|------|--------|
| ← | Move Left |
| → | Move Right |
| SPACE | Jump |
| R | Restart |

---

## 🚀 Installation

```bash
pip install pygame
```

---

## ▶️ Run

```bash
python main.py
```
