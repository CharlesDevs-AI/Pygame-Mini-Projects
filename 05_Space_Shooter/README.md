# 🚀 Space Shooter

A professional 2D Space Shooter game built using **Python** and **Pygame**.

---

## ✨ Features

- 🚀 Player spaceship
- 👾 Random enemy spawning
- 🔫 Bullet shooting
- 💥 Collision detection
- 📈 Live score
- ❤️ Lives system
- 🔄 Restart option
- 🎮 Smooth gameplay
- ❌ Game Over screen

---

## 🛠 Technologies Used

- Python 3
- Pygame

---

---

## 🎮 Controls

| Key | Action |
|------|--------|
| ← | Move Left |
| → | Move Right |
| Space | Shoot |
| R | Restart |
| ESC | Exit |

---

## ▶️ How to Run

```bash
pip install pygame
python main.py
```
