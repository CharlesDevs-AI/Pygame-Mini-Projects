# 🧟 Zombie Survival

A simple 2D Zombie Survival game built using **Python** and **Pygame**.

---

## Features

- Player movement
- Zombies chase the player
- Endless survival gameplay
- Score counter
- Game Over screen
- Restart with **R**

---

## Technologies Used

- Python 3
- Pygame

---

## Controls

| Key | Action |
|------|--------|
| ↑ ↓ ← → | Move |
