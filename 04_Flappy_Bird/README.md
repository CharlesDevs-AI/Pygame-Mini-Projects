# 🚀 Space Shooter

A simple **2D Space Shooter** game built using **Python** and **Pygame**. Control the spaceship, shoot enemies, and survive as long as possible.

---

## 📌 Features

- 🚀 Player-controlled spaceship
- 👾 Random enemy spawning
- 🔫 Bullet shooting system
- 💥 Collision detection
- 📊 Live score tracking
- ❌ Game Over screen

---

## 🛠 Technologies Used

- Python 3
- Pygame

---

## 🎮 Controls

| Key | Action |
|------|--------|
| ← | Move Left |
| → | Move Right |
| Space | Shoot |

---

## ▶️ How to Run

```bash
pip install pygame

python main.py
```
