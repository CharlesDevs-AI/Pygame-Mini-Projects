# 🐍 Snake Game

A classic Snake Game built using **Python** and **Pygame**. Control the snake, collect food, increase your score, and avoid hitting the walls or yourself.

---

## 📌 Features

- Smooth snake movement
- Random food generation
- Live score display
- Game Over screen
- Clean user interface

---

## 🛠 Technologies Used

- Python 3
- Pygame

---

## 📂 Project Structure

```
02_Snake_Game/
│
├── main.py

└── assets/
```

---

## 🎮 Controls

| Key | Action |
|------|--------|
| ↑ | Move Up |
| ↓ | Move Down |
| ← | Move Left |
| → | Move Right |

---

## ▶️ Run

```bash
pip install pygame

python main.py
```
