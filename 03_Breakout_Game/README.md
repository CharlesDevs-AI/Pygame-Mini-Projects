# 🧱 Breakout Game

A classic **Breakout Game** developed using **Python** and **Pygame**. Control the paddle, bounce the ball, break all the bricks, and score points.

---

## 📌 Features

- 🧱 Brick breaking gameplay
- 🎮 Smooth paddle controls
- ⚪ Ball collision detection
- 📊 Live score tracking
- 🏆 Win screen
- ❌ Game Over screen

---

## 🛠 Technologies Used

- Python 3
- Pygame

| Key | Action |
